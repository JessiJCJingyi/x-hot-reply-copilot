隐私政策

本政策说明 X Hot Reply Copilot Chrome 扩展如何处理用户数据。插件只为用户主动请求的热帖识别、资料补全和回复草稿生成功能处理必要数据。

1. 插件处理的数据

  • X 页面内容：当前可见帖子的文字、作者、发布时间及公开互动数据，用于识别热帖和生成回复草稿。
  • 用户提供的资料：产品名称、官网、社媒主页、定位、受众、Bio、语气与禁用表达，用于个性化回复。
  • 公开网页内容：仅在用户主动点击资料导入时，读取用户提供的公开 HTTPS 链接，用于提取产品或人设资料。
  • 模型配置：用户自行填写的 API Base URL、模型名称和 API Key，用于调用用户选择的模型服务。
  • 界面偏好：面板尺寸、启动器位置及相关设置，用于恢复用户界面状态。

2. 数据如何使用与传输

首次启用页面读取前，插件会在设置页展示数据流说明并要求用户主动勾选确认。确认前，插件不会启动热帖扫描或读取帖子内容；用户可以随时取消确认并暂停页面读取。

热帖扫描在浏览器本地完成。当用户主动生成回复或导入资料时，必要的帖子内容、用户资料或公开网页文本会被发送到用户自行配置的模型 API 服务商。数据传输使用 HTTPS。模型服务商对数据的处理受其自身隐私政策和服务条款约束。

开发者不运营中转服务器，不接收用户的帖子内容、产品资料、生成草稿或 API Key，也不会出售这些数据或将其用于广告。

3. 本地与 Chrome 存储

插件使用 Chrome 扩展存储保存设置和界面偏好。非敏感设置可能通过用户登录的 Chrome 账户同步到其其他设备。API Key 只保存在当前设备的 chrome.storage.local 中，不写入 Chrome Sync。用户可在插件设置中修改或清除资料，也可通过卸载插件删除本地数据。

4. 权限用途

  • storage：保存用户配置、产品或人设资料以及界面偏好。
  • x.com / twitter.com：读取当前页面公开帖子并在用户选择后把草稿插入回复框。
  • 模型 API 与用户选择的公开链接：已知模型域名使用固定的最小权限；其他公开 HTTPS 域名仅在用户主动保存或导入时按域名申请访问权限。

5. 数据保留与删除

开发者不保存用户数据。保存在浏览器中的设置由用户控制；用户可以恢复默认设置、删除扩展数据或卸载插件。已经发送给第三方模型服务商的数据，其保留方式由该服务商的政策决定。

6. 未成年人

本产品面向能够管理产品或社交媒体账号的成年人，不面向儿童设计，也不会主动收集儿童信息。

7. 政策更新

如果插件的数据处理方式发生实质变化，我们会在商店页面、官网或插件内更新说明，并在需要时重新取得用户同意。

8. 联系方式

如有隐私问题或删除请求，请通过项目的 隐私请求入口联系开发者。请勿在公开 Issue 中提交 API Key、私人资料或未公开内容。

Chrome Web Store Limited Use 声明：本扩展对用户数据的使用将遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。
