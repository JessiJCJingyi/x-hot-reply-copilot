# Roadmap

This roadmap assumes a side-project pace of 8-12 hours per week.

## Phase 1: Self-Use MVP

Goal: make the workflow useful for one operator.

Scope:

- Hot post radar for visible X posts
- 1h / 3h / 6h / 12h time windows
- Top 5 / Top 10 reply opportunities
- Product profile inputs
- 5-10 reply candidates
- Copy-first reply workflow
- Manual result tracking

Success criteria:

- The operator can reply to 10 hot posts per day.
- At least 70% of ranked posts feel worth reviewing.
- Generated replies require only light editing.

## Phase 2: Growth Validation

Goal: prove the workflow can improve reply visibility.

Scope:

- 7-day manual experiment
- Track post author, age, visible traction, reply mode, and 24h reply views
- Identify best-performing reply modes and post types

Success criteria:

- At least 70 posted replies tracked.
- Baseline average views per reply is known.
- Winning post/reply patterns are visible.

## Phase 3: Private Beta

Goal: test with 10-30 product accounts or founders.

Scope:

- Onboarding for product profile
- Safer UI
- Local logs or lightweight export
- Better reply quality feedback
- Privacy policy and permission explanation

Success criteria:

- 10+ real users install it.
- 5+ users use it for 3 consecutive days.
- 3+ users express willingness to pay.

## Phase 4: Public Launch

Goal: launch a credible public product.

Scope:

- Chrome Web Store listing
- Lightweight website
- Privacy policy
- Support page
- Launch content
- Pricing test

Success criteria:

- 100-300 installs.
- 30+ active users.
- First paying users or strong paid waitlist signal.

## Phase 5: Commercial Version

Goal: monetize once usage and willingness to pay are validated.

Potential paid features:

- No user API key required
- Multiple product profiles
- Higher-quality reply generation
- Reply history
- Advanced hot post scoring
- Influencer watchlist
- Team workspace
- Analytics export

Initial pricing hypotheses:

- Solo: $19-$39/month
- Pro: $49-$79/month
- Team: $99-$199/month
