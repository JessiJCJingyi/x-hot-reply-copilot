# Risk Boundaries

This project is intended as a public-safe workflow package.

## What Is Safe To Share

- Product positioning
- Public workflow
- Reply mode taxonomy
- Safety principles
- Product profile template
- Measurement framework
- High-level roadmap

## What Should Stay Private

- Proprietary scoring weights
- Private high-performing prompt details
- Validated reply example library
- User data
- API keys
- Commercial analytics
- Non-public third-party code
- Friend-provided private extension logic

## Open Source And Third-Party Boundaries

If this workflow is implemented in software:

- Do not copy private extension code.
- Do not copy UI, wording, or proprietary branding from similar products.
- If MIT/Apache/BSD code is reused, keep required license notices.
- If GPL/AGPL code is reused, understand source disclosure obligations before commercial use.
- Avoid using another product's name in a way that implies endorsement.

## Platform Safety

The workflow should keep the human in control:

- no auto-publishing
- no mass-commenting
- no hidden posting
- no impersonation
- no fabricated social proof
- no private data scraping
