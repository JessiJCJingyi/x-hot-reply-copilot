SUPPORT

安装、配置与常见问题

Beta 版本只生成回复草稿，不会自动发布。使用前请准备一个兼容的模型 API Key。

开始使用

  1. 从 Chrome Web Store 安装扩展。
  2. 打开扩展设置，选择模型服务商并填写 API Key。
  3. 选择产品官号或个人号，填写官网、社媒主页或个人 Bio。
  4. 保存后打开 X 首页、For You、搜索页或帖子详情页。
  5. 选择热帖，读取原帖并生成回复草稿。
  6. 编辑、插入并人工确认后发布。

为什么扫描不到 Top 5 / Top 10？

插件只分析当前页面已经加载的公开帖子。请确认页面中已有足够帖子，等待页面完成加载后再次扫描。插件不会在后台无限滚动或抓取未加载内容。

为什么回复没有使用我的 Bio？

请确认已选择正确的产品或个人模式，并在设置页点击保存。生成状态会显示本次使用了多少个个性化字段；如果数字过低，请补充定位、目标受众、语气和禁用表达。

为什么模型请求失败？

请检查 API Base URL、模型名称、Key 状态及账户余额。不同中转站的模型名称可能不同，应以服务商文档为准。插件不会替用户充值或管理第三方账户。

如何报告问题？

请通过项目的 问题反馈入口提交错误截图、发生问题的页面类型、浏览器版本和复现步骤。请勿提交 API Key、私人资料或未公开内容。
