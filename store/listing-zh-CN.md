# Chrome Web Store 上架文案（zh-CN）

## 名称

X Hot Reply Copilot

## 一句话简介

发现近期热帖，并结合你的产品资料与品牌语气生成可编辑的 X 回复草稿。

## 详细说明

X Hot Reply Copilot 是为产品创始人、产品官号和个人品牌设计的 X 回复工作台。

它可以分析当前 X 页面中已经加载的公开帖子，按发布时间与可见互动数据识别值得参与的近期讨论。选择一条帖子后，插件会结合你提供的产品官网、定位、目标用户、个人 Bio、品牌语气与禁用表达，生成多个不同角度的回复草稿。

主要功能：

- 扫描当前页面已加载的近期帖子，展示 Top 5 或 Top 10 回复机会
- 支持产品官号与个人号两种资料模式
- 从用户主动提供的官网、社媒主页或 portfolio 提取公开资料
- 生成价值补充、Builder Lens、轻量产品关联等回复角度
- 支持中文回复和跟随原帖语言
- 复制或插入回复框后继续编辑
- 不自动发布，最终内容始终由用户确认

隐私与控制：

- 每位用户使用自己的模型 API Key
- 热帖扫描在浏览器本地完成
- 只有用户主动生成或导入资料时，必要内容才会发送到用户配置的模型服务商
- 开发者不接收用户的帖子内容、产品资料、草稿或 API Key
- 不包含自动发帖或批量评论功能

当前版本为 Beta。部分网站可能阻止公开资料读取；此时用户可以手动填写资料。模型可用性、价格和数据处理方式由用户选择的第三方服务商决定。

X Hot Reply Copilot 是独立产品，与 X Corp.、OpenAI、DeepSeek、OpenRouter、IKunCode 或其他模型服务商无隶属、赞助或官方合作关系。
